Included in this repository are 2 python source files using tkinter to produce an app that has a primary purpose
of creating a 11" wide by 8.5" high monthly calendar that can be placed on the refrigerator to help with upcoming
holidays and personal events.

The program wakes up in the current month and year with the current day highlighted.

User can advance or go back with + button and - button.

User can go to any month from 1 to 12 or any year from 1000 to 9999 with text boxes.

There is a help button which produces a help screen.

There is a print button which produces screenshot printout to the default printer.

Holidays are entered into the app from editable json files.

Personal events entered are stored automatcally into a PersonalEvents.json file.

The ppctk.py source file is for PC and Linus OS's.

The ppctkmac.py source file is for a Mac with a retina display in which the font sizes had to be made bigger.

The only 2 things you may need to add to your IDE to run this app is tkinter and pillow.
Pillow is needed to help produce the screeshot sent to the printer.

I used to make monthly calendars for my wife for the last 15 years or so using a spreadsheet program and it
take me about 2 hours to produce a yearly calendar.  With this self-written app, it now takes only a few minutes.
It's not perfect but it works very well and it certainly gets the job done.
